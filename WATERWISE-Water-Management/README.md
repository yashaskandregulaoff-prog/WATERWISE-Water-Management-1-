# WATERWISE – Water Consumption Management

## Project Description
WATERWISE is a menu-driven C programming project that monitors water consumption across five campus zones for seven days.

## Objectives
- Monitor daily water consumption.
- Calculate weekly total and average.
- Detect over-limit water usage.
- Identify sudden water consumption spikes.
- Rank zones based on excess water.
- Recommend water conservation actions.

## Technologies Used
- C Programming
- Two-dimensional arrays
- User-defined functions
- Nested loops
- Conditional statements
- Pointers

## Campus Zones
1. Academic Block
2. Hostel
3. Library
4. Cafeteria
5. Sports Complex

## Files
- WATERWISE.c – Complete source code
- Algorithm.txt – Program algorithm
- Testing_Evidence – Testing screenshots
- Conservation_Action_Note.pdf – Water conservation proposal

## Data Notice
Any simulated readings used for testing are clearly labelled as simulated data.

## Conclusion
WATERWISE helps identify unusual water usage and supports better water conservation practices.
